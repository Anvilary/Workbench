# Workbench logo | Locked v1.0

This package locks the approved **modular workbench with four separated parts**:
one tabletop, two angled supports and one stretcher. Brushed charcoal metal with
subtle orange highlights, matching the Anvilary Tools application family.

## Canonical assets

- `source/workbench-approved-original-1254.png`: the archived PNG of the
  user-selected composition, including its badge rendering and black background.
- `master/workbench-frozen-badge-transparent-1254.png`: preferred production master:
  approved Workbench symbol extracted from that image and composited on top of
  the **original frozen Anvilary Application Badge Baseline v1.0**.
- `source/workbench-isolated-symbol-derived-1254.png`: isolated Workbench symbol
  with transparency, raster-derived from approved artwork, no vector master.
- `png/transparent/`: production icons in 12 dimensions, each composited on the
  **exact frozen badge PNG at that dimension**, with unchanged pixels everywhere
  outside the central Workbench symbol.
- `png/original-black-background/`: same symbol over frozen badge against black.
- `png/dark-background/`: same symbol over frozen badge against Anvilary dark.

## Notes

**No changes** were made to the locked Anvilary badge assets; the workbench
symbol is a separate overlay. Because the original approved logo is a raster
composition, the isolated-symbol layer is a mask-derived approximation around
its soft fringe rather than editable vector paths. The archived composition is
retained as a visual reference. Small 16/24/32px versions retain the same
silhouette but naturally reduce the fine metallic effects.
